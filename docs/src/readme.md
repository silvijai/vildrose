# Introduction

Hi, welcome to the docs, these are not the rust API docs, those can instead be found [here](https://silvijai.github.io/vildrose/api/). These docs are for explaining the system structure, the goals, the logic, the choices made and so on.

As mentioned in the contributing.md file as well, feel free to reach out in cases of wanting to contribute, being curious about the project, having issues or otherwise. More things about the project repo and such will also be added here later.

The project is still quite fluid in its early phases. The scope is every changing. Once more systems are developed, I'm sure it'll stabilize, but for now, this should not be seen as anything more than an experiment or hobby project.
