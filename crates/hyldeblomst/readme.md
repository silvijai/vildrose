# vildrose-vm (Hyldeblomst)

The goal of the VM is to emulate a native execution environment for the targeted platforms. For now, the targets are:

Ternary ISAs:
- [Setnex](https://codeberg.org/setnex-org/setnex-isa)
- [REBEL-6](https://github.com/aiunderstand/ternary-workbench/blob/master/docs/rebel6-isa.md)
- 5500FP

Binary ISAs:
- [RISC-V](https://github.com/riscv/riscv-isa-manual)

More can be read about this in the [book](https://silvijai.github.io/vildrose/book/architecture/isa.html).
